# Aula 01 — Introdução à Qualidade de Software

**Atividade:** Diagnóstico de qualidade do projeto-base do professor.

**Fonte do enunciado:** https://afonsolelis.github.io/aulas_senac/pages/qualidade2/material/material_introducao-qualidade.html

## Objetivo

Analisar o projeto `afonsolelis/qualidade_software` sem modificar o código nem escrever novos testes. O enunciado pede: registrar o resultado da suíte (testes aprovados, falhos e ignorados), identificar o que está sem testes, levantar **no mínimo cinco achados reais** e classificar cada um segundo a ISO/IEC 25010, justificando impacto e prioridade.
