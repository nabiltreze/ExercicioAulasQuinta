# Aula 06 — prompts e tarefas (referencia)

Enunciado oficial: https://afonsolelis.github.io/aulas_senac/pages/qualidade2/material/material_ci-github-actions.html

1. **RED -> GREEN:** implementar as regras ate a suite ficar verde, sem alterar testes nem assercoes; conferir matriz regra/caso/teste.
2. **GitHub Actions:** `pull_request` + `push` na `main`, Java 21, Temurin, cache Maven, relatorios e checagem obrigatoria; experimentar falha proposital e recuperacao; configurar branch protection.
3. **ATAM (ciclo 01):** cenarios em seis partes, utility tree, sensibilidade, trade-offs, riscos, evidencias e divergencias da arquitetura.

Esta entrega e uma **reconstrucao demonstrativa** dos tres blocos, nao comprova execucao, PR, red/green ou protecao da main.
