# Aula 04 — Arquitetura e ATAM com apoio de IA

**Status:** reconstrução didática baseada no cronograma de Qualidade 2026.2. Não é cópia literal do roteiro de aula nem evidência de execução dos prompts.

## Objetivo
Planejar a arquitetura de um **Sistema de Organização de Recursos** (salas, professores e materiais), empregando IA para apoiar requisitos, diagramas C4, cenários ATAM e decisões arquiteturais.

## Arquivos
- `prompts/01-requisitos.md` — prompt para levantar requisitos
- `prompts/02-arquitetura-c4.md` — prompt para revisar/desenhar arquitetura
- `prompts/03-analise-atam.md` — prompt de riscos e trade-offs
- `prompts/04-decisoes-adr.md` — prompt de decisões arquiteturais
- `docs/requisitos.md` — requisitos propostos
- `docs/arquitetura-c4.md` — diagramas Mermaid propostos
- `docs/utility-tree-atam.md` — cenários de qualidade e riscos
- `docs/adr-001-persistencia.md` — decisão inicial proposta

## Uso de IA
Os prompts foram redigidos para possível utilização com um assistente de IA; **não foram executados nesta reconstrução**. Os documentos são propostas redigidas a partir dos requisitos públicos do projeto, e precisam ser revistos pelo grupo.
