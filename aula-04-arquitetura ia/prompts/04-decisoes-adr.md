# Prompt 4 — Registro de decisões de arquitetura com IA (reconstruído)

Atue como arquiteto de software. Para o sistema de reservas, produza propostas de ADRs contendo contexto, decisão, alternativas, consequências positivas/negativas, riscos, critérios para reconsiderar e status de aprovação. Inclua ao menos uma decisão sobre banco de dados e controle de concorrência. Não declare soluções implementadas ou aprovadas se ainda estiverem apenas propostas.

**Verificação humana:** aprovar decisões apenas após revisão do grupo e testes correspondentes.
