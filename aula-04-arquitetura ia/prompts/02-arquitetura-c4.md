# Prompt 2 — Arquitetura C4 com IA (reconstruído)

Atue como arquiteto de software. A partir dos requisitos de um sistema de reserva de recursos, proponha diagramas C4 nível Contexto e Contêiner usando Mermaid. Escolha componentes de fronteira, serviço de aplicação e persistência, e explique responsabilidades, integrações e fluxos de reserva. Considere API REST Java/Spring Boot e banco relacional como uma **proposta**, não como requisito obrigatório. Identifique decisões que dependem de validação pelo time e riscos de concorrência e autorização.

**Verificação humana:** validar os limites dos componentes e ajustar diagramas à solução realmente implementada.
