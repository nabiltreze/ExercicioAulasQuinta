**Status da reconstrução:** PARCIAL.

## Tarefa prática reconstruída
Implementar lógica para tornar os testes verdes; criar CI em push/PR; produzir falha deliberada temporária e corrigir; executar primeira avaliação ATAM.

## Entregáveis esperados
Workflow, logs de CI (após execução), relatório ATAM.

## Como demonstrar que foi realizado
1. Criar branch `aula-06` no repositório.
2. Implementar o roteiro e escrever testes quando aplicável.
3. Executar os comandos relevantes e salvar os resultados verdadeiros (não simulados).
4. Abrir pull request com descrição e links para arquivos e para execução do workflow.
5. Marcar como concluído somente após verificar os critérios do professor.
